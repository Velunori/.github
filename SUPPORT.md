# Getting help

Start with the [suite installation guide](https://github.com/Velunori/velunori#install-the-whole-suite), including its requirements, options, updates and recovery steps. Each component's README documents its own settings and limitations.

- **Installation, updates or recovery:** open an installation issue in [Velunori/velunori](https://github.com/Velunori/velunori/issues/new/choose).
- **A component is broken:** use that component's bug-report form. If you cannot identify the component, use the bundle repository.
- **Usage questions:** use the help/question form in the relevant repository. Include what you tried and which instructions you followed.
- **Suggestions or documentation improvements:** use the feature/improvement form in the relevant repository.
- **Security vulnerabilities:** use [private reporting](https://github.com/Velunori/.github/blob/main/SECURITY.md), not a public issue.

Include your Omarchy version, installation method and relevant component commit. For a bundle checkout, `git submodule status` lists the pinned versions. Copy the relevant error text and redact personal information and credentials; do not upload an entire calendar, account store or unreviewed diagnostic archive.

Support is provided through GitHub issues as maintainers have time. There is no guaranteed response time. General Omarchy problems unrelated to Velunori belong with [Omarchy](https://github.com/omacom/omarchy); do not assume a shell crash originates in a Velunori component.
