# Velunori developer documentation

Start with [Contributing](../CONTRIBUTING.md), then choose a path:

| Your goal | Guide |
| --- | --- |
| Improve an existing component | [Development setup](development.md) and [testing](testing.md) |
| Build a new plugin | [Plugin authoring](plugin-authoring.md) and [Hello example](../examples/hello/README.md) |
| Join the Velunori package | [Suite inclusion](suite-inclusion.md) |
| Understand how the pieces fit | [Architecture and ownership](development.md#ownership-boundaries) |

These docs describe the library-based architecture: `lib` for shared UI, optional Floating Bars, and independent feature plugins. They distinguish automated checks from live desktop verification and do not install anything.
